# Ecoparque de Trajouce · 3D interativo (protótipo)

Protótipo de visita 3D interativa ao Ecoparque de Trajouce, preparado para apresentação à Tratolixo.

- Abrir `index.html` num browser recente (Chrome, Edge, Safari ou Firefox).
- Online (GitHub Pages): https://rubarba.github.io/TRATOTESTE/

Navegação: arrastar para mover · botão direito ou Shift para rodar · roda do rato para aproximar · clique num edifício ou camião.

Meteorologia: previsão MET Norway (CC BY 4.0). Protótipo; dados de capacidade e tonelagens com base em documentos públicos da Tratolixo.
